# Direcao Logical Solution

## Objetivo

Aplicar so o que estiver documentado. Campo vazio permanece UNKNOWN.

## Quando nao ativar

Video de outra marca, teste tecnico ou footage sem relacao com a empresa.

## Registro

| Campo                  | Estado         |
| ---------------------- | -------------- |
| Brand guidelines       | UNKNOWN / TODO |
| Tipografia             | UNKNOWN / TODO |
| Cores                  | UNKNOWN / TODO |
| Logo e area de respiro | UNKNOWN / TODO |
| Motion language        | UNKNOWN / TODO |
| Transicoes aprovadas   | UNKNOWN / TODO |
| Identidade sonora      | UNKNOWN / TODO |
| Exemplos aprovados     | UNKNOWN / TODO |
| Exemplos rejeitados    | UNKNOWN / TODO |
| Formatos em uso        | UNKNOWN / TODO |
| Presets de exportacao  | UNKNOWN / TODO |

## Procedimento

1. Procure arquivos de marca no workspace antes de propor cor, fonte ou motion.
2. Se nao houver evidencia, entregue o corte com tipografia neutra (sem logotipo inventado) e marque o que falta.
3. Nao extraia paleta de um frame aleatorio e chame isso de brand.
4. Nao copie identidade de concorrente.

## Definicao de pronto

A entrega lista o que foi aplicado com fonte e o que continua UNKNOWN.
