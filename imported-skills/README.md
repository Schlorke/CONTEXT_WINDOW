# Skills importadas

Cópia de trabalho das skills autorais do Logical Solution, do OkGas e do
Criativos.
Ainda não fazem parte da biblioteca canônica em `saas-skills/`.

Origem usada: `.agents/skills` de cada projeto, na versão mais completa
(pastas `blender/` e `spline/` do Logical Solution, que incluem referências
e scripts; no Criativos, `.agents/skills`, inclusive os pacotes Remotion).
Cópias achatadas em `.claude/skills` e duplicatas só com `SKILL.md` não foram
trazidas.

Fora desta pasta:

- skills da própria biblioteca Context Window já instaladas nesses projetos
- skills de `node_modules`
- snapshots em `tmp/`
