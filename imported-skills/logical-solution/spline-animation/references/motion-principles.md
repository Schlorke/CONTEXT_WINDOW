# Princípios de motion (critério)

O channel map (HTML rAF vs states vs material `tsl.time`) é do skill MCP
`animation`. Não duplicar.

Quando o canal já foi escolhido:

- Timing: entrada mais cara que o idle. Idle quase imperceptível em hero web.
- Anticipation / follow-through: uma pose, não uma coreografia.
- Secondary motion: um detalhe (órbita lenta de highlight), não três loops.
- Reduced motion: se a cena for para este site, respeitar
  `prefers-reduced-motion` no host — ver `spline-web-integration`. Não dá para
  assumir que o overlay HTML lê isso sozinho; confirmar no `html-content`.

Verificar motion com duas fotos em Play, não com uma pose só.
